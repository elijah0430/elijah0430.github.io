Intrinsic vs. Prompted Values in LLMs

Dual Mechanisms of Value Expression

Large language models can express values through learned, intrinsic tendencies or through explicit prompting. This work asks whether those two routes use the same internal mechanisms or distinct ones.

Jongwook Han*, Jongwon Lim*, Injin Kong, Yohan Jo†

*Equal contribution. †Corresponding author.

The mechanisms overlap, but their unique components play different roles: intrinsic components broaden expression, while prompted components strengthen compliance.

Core Question

Do prompted values reuse intrinsic values?

Value alignment often assumes that prompting a model to express a value uses roughly the same mechanism as the model's learned value tendency. This paper tests that assumption mechanistically, using value vectors in the residual stream and value neurons in MLP layers.

Shared

Common components induce value expression

Intrinsic and prompted mechanisms partially overlap at both the vector level and the neuron level.

Intrinsic-unique

Natural expression is more diverse

Intrinsic components promote broader vocabulary and higher lexical diversity in generated responses.

Prompted-unique

Instruction following is stronger

Prompted components increase steerability and compliance with explicit directions, even outside value tasks.

Method

Vectors first, neurons second

The method extracts one value direction per Schwartz value and expression type, then decomposes those directions into shared and unique axes. MLP neurons are assigned functional roles by their alignment with those axes.

1

Collect value responses

Generate responses with no value prompt for intrinsic expression and with value-targeting prompts for prompted expression.

2

Label expression

Classify whether each response expresses the target value, producing expressed and unexpressed sets.

3

Extract directions

Use difference-in-means over residual stream activations to obtain value vectors.

4

Decompose neurons

Identify shared, intrinsic-unique, and prompted-unique neurons from MLP output directions.

Evidence

Overlap exists, but it is not the whole story

Intrinsic and prompted value vectors show positive similarity, and some neurons are shared. The paper then isolates the non-overlapping components to explain why the two routes behave differently.

Behavior

Prompting steers harder; intrinsic values speak more broadly

The behavioral split is the page's main takeaway: prompted mechanisms are more steerable, while intrinsic mechanisms produce richer and more varied language.

Analysis

Shared semantics, distinct control channels

The shared component reconstructs the structure of Schwartz values in representation space, while unique components explain the behavioral tradeoff between natural diversity and direct compliance.

The prompted-unique direction behaves like a broader instruction-following channel. The paper reports that this compliance effect transfers beyond value-expression tasks, which makes it relevant for transparency and safety analysis.
